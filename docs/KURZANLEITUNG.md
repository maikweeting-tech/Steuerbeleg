# Steuerbeleg – Kurzanleitung für Maik und Anna

App: https://maikweeting-tech.github.io/Steuerbeleg/ (am Handy „Zum Startbildschirm hinzufügen“).
Die App ersetzt keine Steuerberatung. Sie berechnet keine Steuer und übermittelt nichts an ELSTER.

## Einmalig
1. **Start** → „Mit Google anmelden“ → Ordner **Steuer** verbinden (gemeinsamer Ordner, Anna hat Bearbeitungsrecht).
2. **Objekte**: Kalkar Wissel und Yerseke mit Einheiten und Verteilschlüssel anlegen, Mieten eintragen.
3. **Kinder**, **Fahrten** (Arbeitstage, Entfernung, Homeoffice-Tage) eintragen.
4. **Check** → Vorlagen für wiederkehrende Belege (Kita, Versicherungen, Grundsteuer) und erwartete Belege (Lohnsteuerbescheinigung) anlegen. Monatliche Erinnerung in den Kalender eintragen.

## Laufend (am besten sofort nach dem Bezahlen)
1. Kameraknopf 📷 → Beleg fotografieren (mehrere Seiten möglich) oder PDF über „Teilen“ an die App schicken.
2. Vorschläge aus der Texterkennung prüfen und „Übernehmen“. Bereich, Kategorie, Person (und Objekt/Kind) wählen → Speichern.
3. Ohne Netz: der Beleg wartet auf dem Handy und wird später übertragen („x warten“).
4. Unklar? Im Beleg das Feld **❓ Frage an den Steuerberater** ausfüllen.
5. Monatlich: **Check** öffnen, rote Zeiträume nachholen oder aus der Vorlage bestätigen.

## Zum Jahresende
1. **Konto**: CSV-Umsätze von Sparkasse Kleve bzw. Volksbank Kleverland laden, „Zahlungen ohne Beleg“ abarbeiten.
2. **Export** → „Aktualisieren“ → Checkliste ansehen, offene Punkte erledigen.
3. **Export** → ZIP-Paket erstellen, in Drive speichern bzw. an die Steuerberatung geben (enthält Belege, Excel, Checkliste, Fragen).

## Nach dem Steuerbescheid
1. **Bescheid** → Bescheiddatum und Einspruchsfrist (aus der Rechtsbehelfsbelehrung) eintragen.
2. „Posten aus Belegsummen anlegen“, Werte laut Erklärung prüfen, Werte laut Bescheid eintragen.
3. Abweichungen (rot) mit der Steuerberatung klären, **vor** Ablauf der Frist.

## Wenn etwas hakt
- „Kein Ordner verbunden“ / Belege fehlen: Start → „Ordner wechseln“ → gemeinsamen Ordner „Steuer“ wählen.
- Lesefehler im Belegindex: Start → „Struktur prüfen / ergänzen“.
- Neue Version angekündigt: „Jetzt neu laden“ tippen.
